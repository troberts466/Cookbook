# Karis Recipe Book PWA v8 Polish

Includes Version 7 and Version 8 polish/features:

- Today's Meal dashboard widget
- Favorite recipes carousel
- Recently added carousel
- Recipe scaling controls
- Cooking Mode
- Step-by-step cooking view
- Timer buttons detected from instruction text
- Smart manual import
- Meal planner
- Grocery list generator
- Backup/import JSON
- Offline PWA support

No Firebase, no Cloudflare Worker, no recipe photos.
